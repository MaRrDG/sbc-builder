# FC Solver PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** FC Solver installs on a phone's home screen, opens full screen, starts fast, shows a clean offline screen, and tells phone users that the EA sync runs on their PC.

**Architecture:** A hand-written service worker (`web/public/sw.js`) caches only Vite's hashed `/assets/*` and an `offline.html` fallback for navigations; it never touches `/api/*` or cross-origin requests. Pure platform rules live in `web/src/pwa/platform.ts` (tested); `install.ts` captures the browser's install prompt before React mounts and exposes `useInstall()`; `components/InstallApp.tsx` renders the sidebar item, the one-time phone banner and the iOS steps sheet. Phone-only copy explains that syncing happens on the PC.

**Tech Stack:** React 19 + Vite 8, plain service worker (no Workbox), `@resvg/resvg-js` for the maskable icon, node:test.

**Spec:** `docs/superpowers/specs/2026-10-12-pwa-design.md`

## Global Constraints

- No push notifications, no offline data, no extension for phones in this plan.
- The service worker never calls `respondWith` for `/api/*`, for navigations except the offline fallback, or for any cross-origin request (Clerk, Paddle, EA, analytics).
- Service worker registered only when `import.meta.env.PROD` is true.
- Cache name `fcs-v1`; `localStorage` key `sbc-pwa-banner` (old `sbc-*` naming kept, CLAUDE.md), every read/write in try/catch.
- Every user-facing string through `t()` in en / ro / it (`npm run i18n:check`); `offline.html` is static and carries its own en / ro / it text.
- UI per `DESIGN.md`: `--go` green only for the primary action; controls 8px radius, containers 14px; works at 390px; respects `prefers-reduced-motion`; dialogs keyboard-accessible (Esc closes, focus returns).
- Analytics only through `track()` with typed events; new events listed in `docs/analytics.md`; no personal data in props.
- Verify with `npm test`, `npm run typecheck`, `npm run build`, `npm run i18n:check`, and in the browser (desktop + 390px).

## Review Focus

- A user who has the app installed and is on a new deploy must get the new JS: navigations are network-only and `/assets/*` names change per build, so a stale shell is impossible — check no step caches `index.html` or `/`.
- Signing in / paying inside the installed app must still work: Clerk and Paddle requests are cross-origin and must not be intercepted — check the fetch handler returns early for `url.origin !== self.location.origin`.
- iPadOS reports a desktop (Macintosh) user agent; `isIos` must use `maxTouchPoints > 1` to catch it (test included in Task 1).
- The banner must never come back after a dismiss or an install, and must not show on desktop or inside the installed app (tests in Task 1).
- `beforeinstallprompt` fires early, often before React renders; listening only inside a component would miss it — `install.ts` starts in `main.tsx` (Task 3).

```ts
// web/src/pwa/platform.ts
// Pure rules for the installable app (PWA): which platform, is it installed, what install help to offer.
export type InstallOffer = 'prompt' | 'ios' | null;

/** Installed and opened from the home screen: the display-mode query, or Safari's own flag on iOS. */
export const isStandalone = (displayModeStandalone: boolean, navigatorStandalone: boolean | undefined) =>
  displayModeStandalone || navigatorStandalone === true;

/** iPhone / iPod / iPad; iPadOS asks for desktop sites with a Mac user agent, so a "Mac" with touch is an iPad. */
export const isIos = (userAgent: string, maxTouchPoints: number) =>
  /iPhone|iPad|iPod/.test(userAgent) || (/Macintosh/.test(userAgent) && maxTouchPoints > 1);

/** A phone (not a tablet, not a desktop): Android browsers say "Mobile" only on phones. */
export const isPhone = (userAgent: string) => /iPhone|iPod/.test(userAgent) || (/Android/.test(userAgent) && /Mobile/.test(userAgent));

/** What install help we can give: the browser's own prompt, the iOS steps, or nothing (installed / not possible). */
export function installOffer(o: { standalone: boolean; ios: boolean; canPrompt: boolean }): InstallOffer {
  if (o.standalone) return null;
  if (o.canPrompt) return 'prompt';
  return o.ios ? 'ios' : null;
}

/** The one-time phone banner: only on phones that can install, never again after a dismiss or an install. */
export const bannerVisible = (o: { phone: boolean; offer: InstallOffer; dismissedAt: number | null; installedAt: number | null }) =>
  o.phone && o.offer !== null && o.dismissedAt === null && o.installedAt === null;
```

```js
// web/public/sw.js
// FC Solver service worker. Deliberately small: Vite's hashed /assets/* come from the cache after the first
// visit (fast start), a failed page load shows /offline.html. Never touches /api/*, pages that load fine, or
// any other origin (Clerk sign-in, Paddle checkout, EA, analytics): those always go to the network.
const CACHE = 'fcs-v1';
const OFFLINE = '/offline.html';
const PRECACHE = [OFFLINE, '/brand/logo-on-dark.svg', '/icon-192.png'];

self.addEventListener('install', (event) => {
  event.waitUntil(caches.open(CACHE).then((c) => c.addAll(PRECACHE)).then(() => self.skipWaiting()));
});

self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches
      .keys()
      .then((keys) => Promise.all(keys.filter((k) => k !== CACHE).map((k) => caches.delete(k))))
      .then(() => self.clients.claim()),
  );
});

self.addEventListener('fetch', (event) => {
  const req = event.request;
  if (req.method !== 'GET') return;
  const url = new URL(req.url);
  if (url.origin !== self.location.origin) return;
  if (req.mode === 'navigate') {
    event.respondWith(fetch(req).catch(() => caches.match(OFFLINE)));
    return;
  }
  if (url.pathname.startsWith('/assets/')) {
    event.respondWith(
      caches.open(CACHE).then(async (c) => {
        const hit = await c.match(req);
        if (hit) return hit;
        const res = await fetch(req);
        if (res.ok) c.put(req, res.clone());
        return res;
      }),
    );
  }
});
```

```ts
// The service worker (web/public/sw.js) runs in production builds only: in dev Vite serves unhashed modules
// that a cache would only get in the way of.
export function registerServiceWorker(): void {
  if (!import.meta.env.PROD || !('serviceWorker' in navigator)) return;
  window.addEventListener('load', () => {
    navigator.serviceWorker.register('/sw.js').catch((e: unknown) => console.warn('[pwa] service worker not registered', e));
  });
}
```

- [ ] **Step 3: Write `install.ts`**

```ts
// web/src/pwa/install.ts
// Install help for the PWA. The browser fires `beforeinstallprompt` early, often before React renders, so
// capture starts from main.tsx and components read it through useInstall().
import { useCallback, useEffect, useState } from 'react';
import { track } from '../track';
import { bannerVisible, installOffer, isIos, isPhone, isStandalone, type InstallOffer } from './platform';

interface PromptEvent extends Event {
  prompt(): Promise<void>;
  userChoice: Promise<{ outcome: 'accepted' | 'dismissed' }>;
}

const KEY = 'sbc-pwa-banner';
type Saved = { dismissedAt: number | null; installedAt: number | null };

function readSaved(): Saved {
  try {
    const v = JSON.parse(localStorage.getItem(KEY) ?? 'null') as Saved | null;
    return { dismissedAt: v?.dismissedAt ?? null, installedAt: v?.installedAt ?? null };
  } catch {
    return { dismissedAt: null, installedAt: null };
  }
}
function writeSaved(s: Saved): void {
  try {
    localStorage.setItem(KEY, JSON.stringify(s));
  } catch {
    /* storage blocked: the banner may show again next visit */
  }
}

let deferred: PromptEvent | null = null;
const listeners = new Set<() => void>();
const changed = () => listeners.forEach((l) => l());

/** Called once from main.tsx, before React renders. */
export function startInstallCapture(): void {
  window.addEventListener('beforeinstallprompt', (e) => {
    e.preventDefault(); // we show our own button / banner instead of the browser's mini-infobar
    deferred = e as PromptEvent;
    changed();
  });
  window.addEventListener('appinstalled', () => {
    deferred = null;
    writeSaved({ ...readSaved(), installedAt: Date.now() });
    track('pwa_installed');
    changed();
  });
}

export interface InstallState {
  offer: InstallOffer;
  phone: boolean;
  bannerVisible: boolean;
  prompt(): Promise<void>;
  dismissBanner(): void;
}

function snapshot() {
  const standalone = isStandalone(window.matchMedia?.('(display-mode: standalone)').matches ?? false, (navigator as Navigator & { standalone?: boolean }).standalone);
  const ios = isIos(navigator.userAgent, navigator.maxTouchPoints ?? 0);
  const offer = installOffer({ standalone, ios, canPrompt: deferred !== null });
  const phone = isPhone(navigator.userAgent);
  return { offer, phone, saved: readSaved() };
}

export function useInstall(): InstallState {
  const [s, setS] = useState(snapshot);
  useEffect(() => {
    const l = () => setS(snapshot());
    listeners.add(l);
    return () => {
      listeners.delete(l);
    };
  }, []);

  const prompt = useCallback(async () => {
    if (!deferred) return; // iOS: the caller opens the steps sheet itself
    track('pwa_install_prompt', { platform: 'android' });
    const e = deferred;
    deferred = null; // a prompt event can be used once
    await e.prompt();
    await e.userChoice.catch(() => null);
    changed();
  }, []);

  const dismissBanner = useCallback(() => {
    writeSaved({ ...readSaved(), dismissedAt: Date.now() });
    changed();
  }, []);

  return {
    offer: s.offer,
    phone: s.phone,
    bannerVisible: bannerVisible({ phone: s.phone, offer: s.offer, dismissedAt: s.saved.dismissedAt, installedAt: s.saved.installedAt }),
    prompt,
    dismissBanner,
  };
}
```

- [ ] **Step 2: Write the component**

```tsx
// web/src/components/InstallApp.tsx
// "Install the app": a sidebar item (when the app can be installed and is not), a one-time banner on phones,
// and on iPhone a sheet with the two Safari steps (iOS has no install prompt).
import { useEffect, useRef, useState } from 'react';
import { DeviceMobile, Export, PlusSquare, X } from '@phosphor-icons/react';
import { useI18n } from '../i18n';
import { useInstall } from '../pwa/install';
import { track } from '../track';

function IosSheet({ onClose }: { onClose: () => void }) {
  const { t } = useI18n();
  const ref = useRef<HTMLDialogElement>(null);
  useEffect(() => {
    const d = ref.current;
    d?.showModal();
    return () => d?.close();
  }, []);
  return (
    <dialog ref={ref} className="ios-install" aria-labelledby="ios-install-title" onClose={onClose} onCancel={onClose}>
      <h2 id="ios-install-title">{t('pwa.iosTitle')}</h2>
      <ol>
        <li><Export weight="bold" aria-hidden="true" /> {t('pwa.iosStep1')}</li>
        <li><PlusSquare weight="bold" aria-hidden="true" /> {t('pwa.iosStep2')}</li>
      </ol>
      <p className="muted">{t('pwa.iosNote')}</p>
      <button type="button" className="ghost bordered" onClick={onClose} autoFocus>{t('pwa.iosClose')}</button>
    </dialog>
  );
}

/** Runs the right install help for this browser; returns the iOS sheet when it is open. */
function useInstallAction() {
  const install = useInstall();
  const [ios, setIos] = useState(false);
  const start = () => {
    if (install.offer === 'prompt') void install.prompt();
    else if (install.offer === 'ios') {
      track('pwa_install_prompt', { platform: 'ios' });
      setIos(true);
    }
  };
  return { install, start, sheet: ios ? <IosSheet onClose={() => setIos(false)} /> : null };
}

export function InstallNavItem() {
  const { t } = useI18n();
  const { install, start, sheet } = useInstallAction();
  if (!install.offer) return null;
  return (
    <>
      <button type="button" className="nav-item" onClick={start}>
        <DeviceMobile weight="bold" aria-hidden="true" />
        <span>{t('pwa.install')}</span>
      </button>
      {sheet}
    </>
  );
}

export function InstallBanner() {
  const { t } = useI18n();
  const { install, start, sheet } = useInstallAction();
  if (!install.bannerVisible) return sheet;
  return (
    <>
      <section className="install-banner" aria-labelledby="install-banner-title">
        <DeviceMobile weight="bold" aria-hidden="true" />
        <div>
          <h2 id="install-banner-title">{t('pwa.bannerTitle')}</h2>
          <p>{t('pwa.bannerText')}</p>
        </div>
        <div className="install-banner-actions">
          <button type="button" className="solve-sm" onClick={() => { start(); install.dismissBanner(); }}>{t('pwa.bannerInstall')}</button>
          <button type="button" className="ghost" onClick={install.dismissBanner} aria-label={t('pwa.bannerClose')}>
            <X weight="bold" aria-hidden="true" />
          </button>
        </div>
      </section>
      {sheet}
    </>
  );
}
```

The four icons exist in `@phosphor-icons/react` (checked: `node --input-type=module -e "import * as p from '@phosphor-icons/react'; console.log(['DeviceMobile','Export','PlusSquare','X'].map(n=>n+':'+!!p[n]).join(' '))"` → all `true`).

Note for `InstallBanner`: on iOS, "Install" opens the sheet and dismisses the banner in the same click; the sheet must still render after the banner is gone, which is why the dismissed branch returns `sheet` rather than `null`.
